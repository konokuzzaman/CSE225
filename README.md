# Travel Management System

Course project for CSE 225.

A console-based travel management system written in C++. Users can sign up, log in, and manage their travel bookings. It uses a custom unsorted list data structure (`unsortedtype.h` / `unsortedtype.cpp`), and data is stored in local text files.

## How to run

Open `Travel Management System.cbp` in Code::Blocks and build, or compile on Windows with:

```
g++ main.cpp -o TravelManagementSystem
TravelManagementSystem
```
